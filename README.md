# DisChord showcase
Este proyecto es un showcase de cómo se puede crear un bot para discord implementando el lenguaje DisChord. Se podrá apreciar lo simple que llega a ser.

# Comenzar a leer
Accede a la carpeta `src` para ver todo el código del bot.

# Cómo descargar y ejecutar (pc).
1. Haz click en el botón de Code -> Download ZIP.
2. Descomprime el zip en la carpeta que desee.
3. Introduzca sus valores secretos en `.env.example` y renombrelo a `.env`
4. Dentro de la carpeta, abra un powershell / terminal y ejecute `chord pkg sync`.
5. Una vez se sincronice su proyecto, escriba `chord run src/index.chord`.
